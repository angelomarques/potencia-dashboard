# YouTube Manager features

- `yt-channels-shell` — channels list page
- `yt-channel-detail` — per-channel queue
- `yt-upload-pending` — R2 upload → pending
- `yt-dry-run-publish` — publish dry-run without live YouTube OAuth
- `yt-preview-video` — Preview → signed R2 URL → inline video
- `yt-delete-video` — Delete button → D1 row + R2 object gone
